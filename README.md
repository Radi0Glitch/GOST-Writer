# GOST-Writer

Кроссплатформенный визуальный (WYSIWYG) редактор текстовых документов по **ГОСТ Р 2.105–2019** и **ГОСТ Р 2.106–2019** (ЕСКД) на базе Markdown (форк [Marked-text-down](https://github.com/Radi0Glitch/Marked-text-down)).

Вы работаете непосредственно на листе **А4 (210×297 мм)** с рамкой **185×287 мм**, боковым штампом и основной надписью **Форма 2 / Форма 2а** (ГОСТ 2.104), видите реальную пагинацию, автоматическую нумерацию разделов, рисунков, таблиц, формул и сносок, а на диске сохраняется чистый текстовый `.md`-файл с метаданными ГОСТ.

**Стек:** C++17 · SDL3 · SDL3_ttf · md4c · tinyfiledialogs · собственный векторный мини-UI и движок вёрстки листов А4 по ЕСКД (без ImGui/Nuklear/WebView).

## Возможности

- **Оформление листа А4 по ГОСТ Р 2.105–2019 и ГОСТ 2.104**:
  - Поля листа А4: левое `20 мм`, верхнее/правое/нижнее `5 мм` (рамка `185×287 мм`).
  - Боковой штамп слева внизу (`12×145 мм`: *Инв. № подл.*, *Подп. и дата*, *Взам. инв. №*, *Инв. № дубл.*).
  - Основная надпись **Форма 2** (`185×40 мм`) на первом текстовом листе и **Форма 2а** (`185×15 мм`) на последующих листах, строки *Копировал* и *Формат А4* под рамкой.
  - Интерактивное заполнение всех граф штампа прямо на листе кликом мыши с навигацией `Tab` / `Shift+Tab` и `Enter`.
- **Титульный лист (раздел 8 ГОСТ Р 2.105–2019)**:
  - Кнопка **«Титул»** включает титульный лист с редактируемыми полями (ведомство/организация, код ОКПД 2, грифы `СОГЛАСОВАНО` и `УТВЕРЖДАЮ`, наименование изделия и вида документа, обозначение, подписи разработчиков в поле 8, год).
  - Поддержка нескольких подписей согласования/утверждения/разработки с автоматическим созданием второго листа титульного листа при переполнении (п. 8.9).
  - Вариант титульного листа **«По ЛУ (8.11)»** (при утверждении документа по листу утверждения, Приложение Г).
- **Автоматическое «Содержание» (п. 6.2) и «ЛРИ» (ГОСТ 2.503)**:
  - Кнопка **«Содержание»** формирует структурный элемент «Содержание» с отточием и реальными номерами листов; клик по строке содержания переносит курсор к разделу.
  - Кнопка **«ЛРИ»** добавляет в конец документа **Лист регистрации изменений** (Форма 2 по ГОСТ 2.503).
- **Полностраничные табличные формы ГОСТ Р 2.106–2019 и шаблоны документов**:
  - Меню **«Шаблоны ↓»** содержит готовые шаблоны:
    1. *Пояснительная записка (ПЗ по ГОСТ Р 2.105, п. 5.2)*
    2. *Спецификация (Форма 1 ГОСТ Р 2.106)* — полностраничная форма с вертикальными заголовками узких граф и подчёркиванием разделов
    3. *Ведомость держателей подлинников (ВД — Форма 4/4а)*
    4. *Табличная ведомость ТП / ЭП / ПТ (Форма 5/5а)*
    5. *Технические условия (ТУ)*
    6. *Руководство по эксплуатации (РЭ)*
- **Автонумерация и правила текста по ГОСТ Р 2.105–2019**:
  - Автоматическая сквозная или пораздельная нумерация разделов, подразделов, пунктов (`1`, `1.1`, `1.1.1`), приложений (`Приложение А`), рисунков (`Рисунок 1 — ...`), таблиц (`Таблица 1 — ...`), формул (`(1)`, `(1.1)`) и примечаний (`Примечание —`, `Примечания 1 ...`).
  - Настройка размера шрифта (`11–14 пт`) и межстрочного интервала (`1,0` / `1,15` / `1,3` / `1,5`).
  - Списки по п. 6.7: дефис (`-`), цифра с точкой (`1.`), строчная буква со скобкой (`а)`).
  - Постраничные **сноски (п. 6.13)**: кнопка **«Сноска»** ставит надстрочный номер в тексте и открывает нижнюю панель редактирования текста сноски; сноски автоматически нумеруются заново на каждом листе и вызывают разрыв страницы при переполнении.
  - Неразрывная привязка числовых значений и единиц физических величин по **ГОСТ 8.417** (п. 6.16.6).
- **Визуальные конструкторы формул, схем и графиков (без ввода кода)**:
  - **Формулы**: дроби, корни, степени, индексы, суммы, произведения, интегралы, матрицы, системы условий и греческие символы + кнопка **«где ...»** для экспликации символов формулы по п. 6.10.6.
  - **Диаграммы**: чёрно-белые блок-схемы (`flowchart TD/LR`) и диаграммы последовательности (`sequenceDiagram`) по п. 6.9.
  - **Графики**: столбчатые, линейные (`xychart-beta`) и круговые (`pie`) диаграммы в чёрно-белом исполнении ГОСТ.
- **Прямой экспорт 1:1 в PDF и DOCX**:
  - Экспорт в **PDF** (через встроенный **Typst**) и в **DOCX / ODT / HTML / EPUB** (через встроенный **Pandoc**) сохраняет точное визуальное соответствие с листом в редакторе — включая рамку А4, боковой штамп, основную надпись Форма 2 / 2а, титульный лист, графики, диаграммы, формулы, таблицы и сноски.

| Сочетание | Действие |
|---|---|
| `Ctrl+N` | Новый документ |
| `Ctrl+O` | Открыть `.md`-файл |
| `Ctrl+S` / `Ctrl+Shift+S` | Сохранить / Сохранить как... |
| `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | Отменить / Повторить |

| `Ctrl+E` | Моноширинный код |
| `Ctrl+Shift+E` | Блок кода |
| `Ctrl+1`, `Ctrl+2`, `Ctrl+3` | Заголовок 1, 2, 3 уровня (Раздел / Подраздел / Пункт) |
| `Ctrl+Shift+L` / `Ctrl+Shift+O` | Маркированный / Нумерованный список |
| `Ctrl+Shift+Q` | Примечание (ГОСТ 6.12) |

## Сборка под Linux

Зависимости (Arch Linux):

```sh
sudo pacman -S sdl3 sdl3_ttf meson ninja zenity
```

Сборка и запуск:

```sh
meson setup build --buildtype=release
ninja -C build
./build/marked-text-down
```

Или сборка готовых дистрибутивов (Linux `.tar.gz` и Windows NSIS `.exe` установщик) одной командой:

```sh
./build.sh --linux --windows --test --sign
```

Установка в систему (бинарник, шрифты, `.desktop`-файл и иконка):

```sh
sudo ninja -C build install
```

### Arch Linux: сборка пакета из git (PKGBUILD / AUR)

Пакет в AUR пока не опубликован (будет выложен вместе с `marked-text-down-git`, как только откроется регистрация в AUR), но `PKGBUILD` уже лежит в репозитории и тянет исходники напрямую из git — собирается и устанавливается штатным `makepkg` без AUR:

```sh
git clone https://github.com/Radi0Glitch/GOST-Writer.git
cd GOST-Writer/packaging/aur
makepkg -si            # собирает gost-writer-git и устанавливает в систему
```

После публикации в AUR станет доступна прямая установка через AUR-хелперы:
`yay -S gost-writer-git` (или `yay -S marked-text-down-git` для классической ветки редактора) — сам `PKGBUILD` не изменится.

## Кросс-компиляция под Windows и сборка NSIS-установщика

Для сборки Windows-версии (`x86_64`) на Linux используются `mingw-w64-gcc` и `nsis`:

```sh
sudo pacman -S mingw-w64-gcc nsis
./build.sh --windows
```

Готовые сборки располагаются в каталоге `dist/`:
- `dist/GOST-Writer-Setup-x86_64.exe` — установщик для Windows x86_64 (с поддержкой русского и английского языков, ярлыками, ассоциациями `.md` и деинсталлятором).
- `dist/GOST-Writer-linux-x86_64.tar.gz` — portable-архив для Linux x86_64 (включает бинарник, шрифты, Pandoc и Typst).

### Проверка подписи релиза

Релизы подписаны GPG-ключом автора. Публичный ключ лежит в файле `KEYS.asc` в репозитории.

Отпечаток ключа: `56B089B00314055750AC5EF1F97C07F236D69415`

```sh
gpg --import KEYS.asc
gpg --fingerprint 56B089B00314055750AC5EF1F97C07F236D69415
gpg --verify GOST-Writer-linux-x86_64.tar.gz.asc GOST-Writer-linux-x86_64.tar.gz
gpg --verify GOST-Writer-Setup-x86_64.exe.asc GOST-Writer-Setup-x86_64.exe
```
